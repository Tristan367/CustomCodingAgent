{# Options for a model dropdown, grouped by who serves the model. OpenRouter resells nearly everything the first-party providers offer, so a flat list showed "Claude Opus 5" and "Gemini 2.5 Pro" with no way to tell which key, which price, and which rate limit you were about to use. The grouping is a native , so the answer is on screen without a longer label on every row. Custom endpoints come first because they are the ones the user set up by hand and reaches for most; everything else follows alphabetically, which is what Jinja's groupby gives for free. A user with no custom endpoints gets no such group at all. One macro for all three dropdowns -- new session, session model, subagent model -- because they drifted apart the last time they were three copies. #} {% set CUSTOM_GROUP = 'Custom endpoints' %} {% macro _option(m, selected, with_data) -%} {%- endmacro %} {% macro model_options(models, selected, skip_custom=false, with_data=false) %} {% set shown = models | rejectattr('needs_model_id') | list if skip_custom else models %} {% set custom = shown | selectattr('provider_name', 'equalto', CUSTOM_GROUP) | list %} {% if custom %} {% for m in custom %} {{ _option(m, selected, with_data) }} {% endfor %} {% endif %} {% for provider_name, group in shown | rejectattr('provider_name', 'equalto', CUSTOM_GROUP) | list | groupby('provider_name') %} {% for m in group %} {{ _option(m, selected, with_data) }} {% endfor %} {% endfor %} {% endmacro %}
